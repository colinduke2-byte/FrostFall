# Frostfall

A browser 8-bit action RPG. Open the page and play; press F11 (or use Pause > System > FULLSCREEN) for full screen.

Play: enable GitHub Pages for this repo (Settings > Pages > Deploy from a branch > main, root) and open the link it shows.

Controls are in Pause > System. Keyboard, mouse, touch and gamepads (RB / your cast button backs out of any menu) all work.
